# Technical Writer Toolkit — free edition

A small, practical sample of templates and review tools for software documentation. Use it to plan a documentation effort, write a getting-started guide or how-to, and review a draft.

## What is included

| Folder | Contents |
|---|---|
| `templates/` | Getting-started guide and how-to guide templates |
| `checklists/` | Documentation planning and editorial review checklists, plus a document review sheet |
| `planning/` | Documentation plan template |
| `style-guide/` | Technical writing style guide |
| `glossary/` | Glossary template |

The complete toolkit contains additional templates, checklists, planning tools, API documentation examples, Docusaurus references, and a searchable PDF. The paid-edition link will be added here when available.

## Get started

1. Choose a template and copy it into your documentation repository.
2. Replace the bracketed placeholders with product-specific information.
3. Use the planning checklist before starting a larger documentation effort.
4. Review your draft with the editorial checklist or review sheet.

The fictional Parcelwise examples are illustrative. Verify every instruction, command, product detail, and link against your own product before publishing.
